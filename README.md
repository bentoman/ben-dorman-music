# Ben Dorman — Musical Theatre

A lightweight static portfolio site. It has no framework, build step, or package dependencies and is ready for GitHub Pages.

The Japanese view is available at `?lang=ja`. Its translated page copy and catalogue data live in `docs/i18n-ja.js`; both languages share the same artwork and layout.

## Preview locally

Serve the `docs` folder with any static web server, then open its local address in a browser.

## Edit the content

- Production and music entries: `docs/data.js`
- Page copy and section structure: `docs/index.html`
- Japanese copy and catalogue entries: `docs/i18n-ja.js`
- Visual styling and responsive layouts: `docs/styles.css`
- Production artwork: `docs/assets/`

Album cards currently lead to Ben's Bandcamp catalogue. They can be replaced with exact album URLs as those are confirmed. The featured *Big Blue Bucket* video space is ready for a future revised animation.

## GitHub Pages

The published site is the contents of `docs`. In the repository's **Settings → Pages**, choose **Deploy from a branch**, then select the **main** branch and the **/docs** folder.
